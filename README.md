# OS Skins
A root app for Meta Quest (Horizon OS) that recolors the system UI with a single color. You pick a color, and the Settings panel, dock, system UI, Store, Library and other Meta apps all switch to that color.

Root is required. Grant OS Skins in Magisk › Superuser.

Features
One color picker (saturation/value square, hue bar, hex box) plus 8 presets
Live preview of the quick settings panel and dock
Panel brightness, background color amount, and button text color (Auto / Black / White)
Per-app on/off (Settings › Apps). Settings panel, Home & dock and System UI are always on.
Applying takes about 1 second, and Restore puts Meta's stock colors back
Apply on boot: your color comes back after a restart (via a small Magisk module)
Detects the live color on launch, including colors applied by rasp.alone OS Colors
